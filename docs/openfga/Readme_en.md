# Authorization Stores in the User Authentication System

In the user authentication system, the following authorization models are constructed using OpenFGA.

|Store|Note|
|-|-|
|[API Execution Permission Management Store](./api-authz-model_en.md)|Manages execution permissions for APIs provided by the user authentication system.|
|[Realm-Store Mapping Management Store](./realm-store-binding-model_en.md)|Manages the owning realm of stores created through the store registration API.|
|[Operator / Attribute (Plant) Management Store](./operator-plant-model_en.md)|Manages access permissions for business entity information and attribute (office) information resources.|
