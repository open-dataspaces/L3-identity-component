# ユーザ認証システム 認可ストア

ユーザ認証システムでは OpenFGA を用いて以下の認可モデルを構築しています。

| Store | Note |
| --- | --- |
| [API実行権限管理ストア](./api-authz-model.md) | ユーザ認証システムが提供するAPIの実行権限を管理 |
| [レルム・ストア紐づけ管理ストア](./realm-store-binding-model.md) | ストア登録APIで作成したストアの所有レルムを管理 |
| [事業者・属性(事業所)管理ストア](./operator-plant-model.md) | 事業者情報・属性(事業所)情報リソースのアクセス権限を管理 |
