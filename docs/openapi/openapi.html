概要

本APIは、認証および事業者・属性情報を扱うためのエンドポイント群を提供します。
全てのエンドポイントは CORS（Cross-Origin Resource Sharing）に対応しています。
※許可されるオリジンは、事前に登録された信頼済みのドメインに限定されます。

code_challenge
required
string

PKCE用コードチャレンジ

  • 認可リクエストで使用するPKCE用のチャレンジ文字列を指定します。
    チャレンジ方式はS256で、以下手順でコードを生成します。
  1. code_verifier を生成（ランダムな文字列）
  • 長さ：43〜128文字（RFC 7636で定義）
  • 文字種：英数字（A-Z, a-z, 0-9）と -, ., _, ~ のみ（URLセーフな文字）
  1. code_verifier を SHA256 でハッシュ
  2. ハッシュ値を Base64URL エンコード
  • code_verifierはトークン取得APIのリクエスト時にも必要になる値です。
